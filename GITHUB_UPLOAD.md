# GitHub upload notes

This directory is the GitHub-ready source tree for YouTube Creator Data Hub v1.2.1.

Included: source code, static UI source, configuration templates, documentation, scripts, Skill metadata, version and changelog.

Excluded: SQLite databases, generated dashboard output, exports, caches, logs, secrets/API keys, and release-package manifests.

Important: GitHub's web repository uploader does not unpack ZIP files into a repository. Extract the ZIP first, then upload the contents of the `YouTube_Creator_Data_Hub` folder, or initialize it with Git and push normally.
