YouTube Creator Data Hub V3.10.4 覆盖升级包
===========================================

适用基线：V3.10.3
升级入口：upgrade.cmd

本版修复
--------
1. 左侧 Builder 恢复自然高度
   - 指标构建器不再被“已构建指标”的内容数量反向撑高。
   - 规则 / 标签构建器同理。
   - “保存指标 / 清空输入”下面只保留正常 Card padding，不再产生大块空白。

2. 右侧列表跟随左侧高度
   - 已构建指标高度 = 指标构建器自然高度。
   - 规则列表高度 = 规则 / 标签构建器自然高度。
   - 右侧内容超过可见区域时只在 Card Body 内纵向滚动。
   - 继续固定 10 条 / 页。
   - 搜索、排序、翻页不会改变外部 Card 高度。

3. 动态高度同步
   - Builder 增加 ResizeObserver。
   - 切换指标类型、增删规则条件、调整窗口尺寸后会自动重新计算高度。

安装
----
1. 关闭 Dashboard。
2. 将 ZIP 全部内容解压覆盖到现有 V3.10.3 项目根目录。
3. 双击 upgrade.cmd。
4. 完成后运行 start-dashboard.cmd。
5. 浏览器按 Ctrl+F5 强制刷新。

数据
----
- 不删除、不覆盖 creator_hub.sqlite。
- Schema 不变。
- 不清空已有博主、视频、商业数据、指标、规则或筛选配置。
- upgrade.cmd 首步仍会创建一致性 SQLite 备份。
