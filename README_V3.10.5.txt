YouTube Creator Data Hub V3.10.5 覆盖升级包
===========================================

适用基线：V3.10.4
升级入口：upgrade.cmd

本版目标
--------
解决 V3.10.4 中“规则 / 标签构建器”和“规则列表”视觉上过矮的问题，
但不回退到“右侧列表反向把左侧 Builder 撑高”的旧逻辑。

V3.10.5 调整
-------------
1. 规则 / 标签构建器桌面端约 500px 最小高度。
2. 内部改成更清晰的三段式纵向结构：
   - 规则名称 / 分组 / 说明
   - 条件设置
   - 保存 Footer
3. 规则说明 textarea 加高。
4. 条件区增加“条件设置”标题和说明。
5. “添加条件”从保存按钮组中拆出，放在条件区底部。
6. “保存规则 / 清空”放到独立 Footer。
7. 规则列表高度继续严格跟随规则构建器。
8. 规则列表继续 10 条 / 页，并在 Card 内纵向滚动。
9. 小屏幕自动取消 500px 最小高度，恢复自然纵向布局。

升级方法
--------
1. 关闭 Dashboard。
2. 将 ZIP 全部内容解压覆盖到现有 V3.10.4 项目根目录。
3. 双击 upgrade.cmd。
4. 完成后运行 start-dashboard.cmd。
5. 浏览器按 Ctrl+F5 强制刷新。

数据安全
--------
- 不删除或覆盖 creator_hub.sqlite。
- 不修改业务数据。
- Schema 不变。
- 升级前继续创建一致性 SQLite 备份。

README.md

本覆盖包同时包含适配 V3.10.5 的完整 README.md；解压覆盖时会同步更新仓库根目录 README.md。
