# GitHub public-repository presentation

Recommended **About** description:

> Local-first YouTube Creator Intelligence platform: SQLite fact store, Workspace semantics, durable jobs, FastAPI, synthetic demo, benchmarks and auditable AI evaluation.

Recommended topics:

`creator-intelligence`, `youtube-data-api`, `fastapi`, `sqlite`, `data-product`, `influencer-marketing`, `ai-evaluation`, `python`, `analytics`, `portfolio-project`

Repository homepage priorities:

1. README demo instructions and architecture should be visible before version-history detail.
2. Add 2-4 screenshots or a short GIF generated from the synthetic demo only.
3. Keep production databases, API keys and business exports out of Git.
4. Use semantic commit messages instead of `Add files via upload` for future changes.
5. Each release should include Highlights, Compatibility/Migration, Performance evidence, Fixes and Known Issues.
6. When benchmark or AI-eval results are published, include their machine/model configuration.

Suggested release asset policy: source ZIP plus an optional Windows overlay ZIP and SHA-256 checksum. Never publish a database copied from production.
