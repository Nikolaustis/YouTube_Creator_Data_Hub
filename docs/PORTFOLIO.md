# Public portfolio workflow

## Reviewer path

On Windows:

```bat
setup-demo.cmd
start-demo.cmd
```

This creates `data/demo_creator_hub.sqlite` with deterministic synthetic data and opens the full Dashboard. No YouTube or AI API key is required.

For the typed API:

```bat
start-api.cmd --db data\demo_creator_hub.sqlite
```

## What the demo contains

The default fixture contains 100 synthetic Creators and 3000 synthetic Videos, historical snapshots, one discovery run, Workspace brands, a generic content taxonomy, Creator relationships, revenue/orders metrics and mock AI findings/evidence.

All names, metrics and relationships are synthetic. The demo must never be presented as production or customer data.

## Evidence policy

Resume bullets and README performance claims should use values generated by `creator_hub.portfolio.benchmark`. AI-quality claims should use `creator_hub.portfolio.ai_eval` against saved model outputs. Do not invent or extrapolate numbers.
