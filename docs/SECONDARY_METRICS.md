# 二次指标工作区

二次指标页面是独立的运营分析层，不改变 YouTube Fact Store。

## 数据来源

- 博主客观字段：订阅数、频道累计播放量、YouTube视频总数、本地已存视频数、品牌视频数量等。
- 视频客观字段：当前播放量、点赞、评论、时长、发布时间。
- 系统视频分类：UgPhone、竞品、日常、多品牌云手机、其他云手机、待复核。
- 人工修正：如存在，最终分类优先使用人工修正；否则使用系统识别。

依赖视频分类的统计仍属于系统确定性聚合，不伪装成 YouTube 原始字段。

## 大数据实现

浏览器不读取全部视频。Dashboard 构建时由 Python 为每位博主预聚合：

- 全部视频；
- 最终分类（系统识别 + 可选人工修正）；
- 品牌；
- 全部时间 / 近7 / 30 / 60 / 90 / 180 / 365天；
- 播放量 / 点赞 / 评论 / 时长的 count、sum、avg、median、min、max。

精确开始/结束日期属于动态范围，由交互 Dashboard 调用 Python/SQLite 计算，并缓存该指标的博主级结果；不会因此把几十万条原始视频送入浏览器。

## 四类指标

全局展示四类指标：

1. **客观数据**：系统基础事实或确定性统计，例如订阅数、频道累计播放量、UgPhone视频数量。
2. **聚合标签**：0/1 博主身份，例如合作过博主、未合作博主、LDCloud/RedFinger/VSPhone合作博主。
3. **构建指标**：指标构建器的输出之一。
4. **比值指标**：指标构建器的另一种输出。

### 指标构建器输入/输出

输入类型只有：

- 【客观数据】
- 【聚合标签】

输出类型只有：

- 【构建指标】
- 【比值指标】

当输出为【构建指标】时：

- 输入可为客观数据或聚合标签；
- 使用 Count / Sum / Average / Median / Max / Min；
- 视频客观数据可以叠加视频分类/品牌筛选和时间范围。

当输出为【比值指标】时：

- 输入自动锁定为【客观数据】；
- 分子和分母分别定义一个客观视频数据聚合逻辑；
- 两侧都可单独选择视频标签、聚合方式和时间范围；
- 最终计算分子 ÷ 分母。

## 时间范围

涉及视频时间的指标支持：

- 全部时间
- 近7天
- 近30天
- 近60天
- 近90天
- 近180天
- 近365天
- 指定开始日期 + 结束日期

## 规则与筛选

规则条件可引用：

- 客观数据
- 聚合标签
- 构建指标
- 比值指标

第一条条件不显示布尔连接词。从第二条条件开始，每条独立选择：

- AND：在当前结果中继续要求满足该条件
- OR：满足当前结果或该条件均保留
- NOT：在当前结果中排除满足该条件的对象

聚合标签为布尔标签，选择具体标签即表示“存在/为真”，不显示数字阈值。

同样的多条件 AND / OR / NOT 逻辑应用于总览博主库、二次指标应用结果、博主详情、视频分类、博主发现本次结果和历史发现记录。
